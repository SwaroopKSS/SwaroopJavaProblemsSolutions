# Java Data Structures & Algorithms - Complete Cheat Code Guide

## 📚 Overview
A comprehensive collection of famous data structures and algorithms in Java with easy explanations, implementations, and patterns to remember.

---

## 🎯 What's Covered

### 1️⃣ **ARRAYS** (Foundation)
- Two Pointers
- Sliding Window
- Prefix Sums
- Kadane's Algorithm
- **Remember**: Arrays = O(1) access, O(n) insertion/deletion

### 2️⃣ **LINKED LISTS** (Linear DS)
- Singly/Doubly Linked Lists
- Reversal
- Floyd's Cycle Detection
- Merge/Split Operations
- **Remember**: LL = O(1) insertion/deletion at head, O(n) access

### 3️⃣ **STACKS** (LIFO)
- Expression Evaluation
- Parentheses Matching
- Monotonic Stacks
- **Remember**: LIFO = Last In First Out (think stack of plates)

### 4️⃣ **QUEUES** (FIFO)
- Simple Queue
- Circular Queue
- Deque
- BFS Implementation
- **Remember**: FIFO = First In First Out (think line at bank)

### 5️⃣ **TREES** (Hierarchical)
- Binary Tree Traversals (Inorder, Preorder, Postorder, Level Order)
- Binary Search Tree
- AVL Tree (Self-balancing)
- Segment Trees
- **Remember**: Root at top, leaves at bottom

### 6️⃣ **GRAPHS** (Networks)
- DFS (Depth-First Search)
- BFS (Breadth-First Search)
- Dijkstra's Algorithm
- Floyd-Warshall
- Topological Sort
- **Remember**: Vertices + Edges = Graph

### 7️⃣ **SORTING** (Arrangement)
- Bubble Sort: O(n²)
- Selection Sort: O(n²)
- Insertion Sort: O(n²)
- Merge Sort: O(n log n) - Stable, Divide & Conquer
- Quick Sort: O(n log n) avg - Partition-based
- Heap Sort: O(n log n) - In-place
- Counting Sort: O(n+k) - Non-comparative

### 8️⃣ **SEARCHING** (Finding)
- Linear Search: O(n)
- Binary Search: O(log n)
- Two Pointers
- **Remember**: Binary search needs SORTED array

### 9️⃣ **HASHING** (Fast Lookup)
- HashMap/HashTable
- HashSet
- Collision Handling (Chaining, Open Addressing)
- **Remember**: O(1) average lookup

### 🔟 **DYNAMIC PROGRAMMING** (Optimization)
- Memoization (Top-down)
- Tabulation (Bottom-up)
- Fibonacci, Knapsack, LCS, Edit Distance
- **Remember**: Overlapping subproblems + Optimal substructure
