BIG O NOTATION:
  O(1)      → Constant           (hash lookup, array access)
  O(log n)  → Logarithmic        (binary search, balanced tree)
  O(n)      → Linear             (simple loop)
  O(n log n) → Linearithmic      (merge sort, quick sort avg)
  O(n²)     → Quadratic          (nested loops, bubble sort)
  O(2ⁿ)     → Exponential        (recursion without memoization)
  O(n!)     → Factorial          (permutations)

DATA STRUCTURES OPERATIONS:
  Array:        Access O(1), Insert/Delete O(n)
  LinkedList:   Insert/Delete O(1) at head, Access O(n)
  Stack:        Push/Pop O(1)
  Queue:        Enqueue/Dequeue O(1)
  BST:          Search/Insert/Delete O(log n) avg
  HashMap:      All operations O(1) avg
  Heap:         Insert/Delete O(log n)
