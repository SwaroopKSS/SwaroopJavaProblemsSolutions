💡 MEMORY TRICKS (QUICK RECALL):

Arrays         → "All Accesses Are O(1)"
LinkedLists    → "Loop → Link → Linear"
Stacks         → "Stacks Stack on top (LIFO)"
Queues         → "Queue like a Queue at ticket counter (FIFO)"
Trees          → "Tree Traversal: In-Pre-Post-Level"
Graphs         → "DFS = Deep, BFS = Broad"
Sorting        → "Bubble=Slow, Merge=Stable, Quick=Fast"
DP             → "DP = Divide Problem + Store Results"
Backtrack      → "Build Path → Explore → Undo"

════════════════════════════════════════════════════════════════════════════════

⚡ BIG O CHEAT SHEET:

O(1)      → Constant      (hash lookup, array access)
O(log n)  → Logarithmic   (binary search)
O(n)      → Linear        (simple loop)
O(n log n) → Linearithmic  (merge/quick sort)
O(n²)     → Quadratic     (nested loops)
O(2ⁿ)     → Exponential   (subsets)
O(n!)     → Factorial     (permutations)
