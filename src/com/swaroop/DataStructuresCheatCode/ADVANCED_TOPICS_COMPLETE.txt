💡 KEY INSIGHTS FROM ADVANCED TOPICS
═══════════════════════════════════════════════════════════════════════════════

GREEDY ALGORITHMS:
   Problem: Local optimization vs global optimization
   Solution: Verify greedy property holds for the problem
   Key insight: Activity selection uses earliest-finish-time heuristic

STRING ALGORITHMS:
   Problem: Naive pattern matching is O(n*m)
   Solution: KMP builds failure function for O(n+m)
   Key insight: Pre-processing pattern saves matching time

BIT MANIPULATION:
   Problem: Seems like magic, hard to remember
   Solution: Understand XOR and bit properties fundamentally
   Key insight: Brian Kernighan trick: n & (n-1) removes rightmost bit

INTERMEDIATE DP:
   Problem: DP seems like exhaustive search
   Solution: Identify overlapping subproblems and build bottom-up
   Key insight: LIS has O(n²) naive DP but O(n log n) with binary search

ADVANCED GRAPHS:
   Problem: Different algorithms for different constraints
   Solution: Understand input constraints (negative weights? directed?)
   Key insight: Kruskal (edge-focused) vs Prim (vertex-focused)

ADVANCED TREES:
   Problem: Tree traversal with O(1) extra space? Impossible!
   Solution: Morris traversal uses tree structure as implicit stack
   Key insight: Temporarily modify tree during traversal, restore after
