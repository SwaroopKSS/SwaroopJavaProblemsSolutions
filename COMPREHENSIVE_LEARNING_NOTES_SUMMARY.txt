🎯 KEY INSIGHTS BY TOPIC
═══════════════════════════════════════════════════════════════════════════════

ARRAYS:
├─ Two-pointer = solve pair/reverse/duplicate problems
├─ Sliding window = solve subarray/substring problems
├─ Prefix sum = turn O(n) queries into O(1)
└─ Kadane's = find max subarray elegantly

LINKED LISTS:
├─ Fast/slow pointers = detect cycles/find middle
├─ Reversal = essential technique
├─ Dummy node = simplifies edge cases
└─ Always save next = most common mistake to avoid

STACKS:
├─ Use = DFS, undo, parentheses, recursion
├─ Monotonic = solve "next greater" problems
├─ Min stack = track minimum while pushing
└─ Always check empty = prevent crashes

QUEUES:
├─ Use = BFS, scheduling, level-order
├─ Deque = sliding window maximum
├─ Priority = when order matters
└─ Always check empty = prevent crashes

TREES:
├─ DFS = depth-first, recursive
├─ BFS = breadth-first, uses queue
├─ In-order BST = sorted output!
└─ Always null-check = most common bug

GRAPHS:
├─ DFS = recursive traversal
├─ BFS = queue-based traversal
├─ Dijkstra = shortest path
└─ Topological = order dependencies

DYNAMIC PROGRAMMING:
├─ Define state = most important step
├─ Find transition = how to compute from previous
├─ Memoization = top-down caching
└─ Tabulation = bottom-up building
